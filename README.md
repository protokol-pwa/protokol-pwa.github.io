# Протокол → обучающее видео

Зеркало приложения. Основной адрес — https://first-aid-8er.pages.dev,
здесь лежит ровно та же собранная версия на случай, если основной адрес
не открывается из какой-то сети.

Приложение работает целиком в браузере: PDF-протокол ОСКЭ разбирается на
шаги и проигрывается со слайдами, озвучкой и субтитрами. После первого
открытия оно сохраняется на устройстве и дальше работает без сети.

Исходный код здесь не лежит — только готовая сборка.
